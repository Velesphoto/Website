To add a photo: drop a .jpg, .png, .webp, .gif or .avif file into the matching folder and commit it. It shows up in the gallery and under the right filter button, with no HTML edits.

Captions come from the file name. For example, 03-open-kitchen.jpg becomes “Real estate · open kitchen”.
Order is alphabetical within each category, so a number prefix like 01- or 02- controls it. The leading number is dropped from the caption.
Lightbox: clicking a photo opens it full size. Click again or press Esc to close it.
